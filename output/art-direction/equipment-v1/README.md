# Retained equipment source art

These twelve source cutouts are retained from the former art study because inventory equipment icons still use them. Runtime copies remain in `public/grotesque/items/`. Old anatomy, adapters, full-body assemblies and animation art have been removed.

Use one transparent cutout per icon archetype, a recognizable silhouette, shared frontal lighting and a declared grip or wearing anchor. Weapons must have handles rather than hands or limb joints. For a runtime icon, uniformly fit the source inside a maximum 256-pixel frame with nearest-neighbour sampling and preserved alpha.

The new creature renderer uses registered crown and cleaver artwork from the modular library. Other equipment still uses these icon archetypes. Wrapping hood artwork is unsuitable for worn headgear and is superseded by the crown interface; inventory artwork and item names await the dedicated equipment pass.
